# Router-Conditioned Sparse Recoverability Under Equal Global Training/Recovery Budgets

Purpose: complete the canonical empirical mapping (expert count, source seed, router age, sparsity) to native sparse recoverability. This is Dataset A, not exposure matching or a mechanism study.

Architectures: 8, 12, 16, 24, 32 experts. Seeds: 7, 17, 29, 43, 61; the preferred new seeds are verified by `new_seed_audit.json`. Reproducibility reruns are not additional seeds. Router ages: 0 through 100 in increments of 10. Sparsities: 0.70, 0.75, 0.80, 0.85, 0.90, 0.95. Expected sparse rows: 1650; dense conditions: 275; source trajectories: 25.

Source-training budget: 2500 attempts, batch size 128, sequence length 128, gradient accumulation 1, 40,960,000 input-token occurrences. Router age r maps to source step 25r. Missing source checkpoints require one same-budget reconstruction; all overlapping historical state hashes must match before reusing recoveries. Checkpoint-only saving preserves evaluation cadence. Source exposure logging is passive and CUDA trajectory-invariance tested.

Recovery budget: 2500 attempts with fresh AdamW, learning rate 0.0003, weight decay 0.01, clipping 1, no scheduler or warmup, historical fp16/GradScaler behavior, auxiliary weight 0.1. Native learned trainable routing only. Successful updates may differ from attempted steps. Runtime uses historical PyTorch 2.7/CUDA 12.8 and OMP_NUM_THREADS=4.

Pruning protocol: jointly rank the two weight matrices inside each expert by source-R100 magnitude; retain the historical rounded count at each sparsity, exclude biases, and reuse one mask per architecture/seed/sparsity across ages. Surviving expert and shared parameters rewind to source R0; only the initial router comes from the selected age. Final pruned weights must remain zero.

Dense comparator: one native dense recovery per architecture/seed/router age, shared across six sparsities. The ticket gap is sparse final validation loss minus that matched dense final validation loss. A dense R100 endpoint is never a universal comparator. Pruning shock is matched rewound sparse initial loss minus dense initial loss. `sparse_preprune_validation_loss` denotes the equivalent unmasked rewound model's matched dense initial evaluation, not a new pruning evaluation of R100. Early AUC is the historical trapezoidal integral of validation loss over steps 0–1250, sampled every 50 steps; no division by interval length.

Exposure caveat: equal global budgets do not equalize accepted tokens per expert, active expert updates, or developmental maturity. Complete counters are used where available; historical sampled proposed-assignment exposure remains a separately named developmental metric. Population SD is used for expert load CV; sample SD (ddof=1) is used across independent seeds. Router ages, sparsities, experts and tokens are not independent replicates.

Historical artifact reuse policy: audit every candidate's checkpoint config, source component identity, mask/rewind hash, data sequence, native routing, recovery settings, final masked zeros and raw endpoint. Preserve valid historical artifacts in place and link by path. Duplicate valid candidates are retained in the audit but one endpoint is selected deterministically. Never select seeds or rerun criteria based on outcomes.

Dataset schema: `schema.json` documents the frozen condition-level columns when the build completes. Raw condition-level CSV and derived condition-level CSV remain separate. Summary tables aggregate seeds, not artificial extra replicates; when ages or sparsities are marginalised, first compute a within-seed average. `run_manifest.csv` tracks source/dense/sparse jobs and distinguishes PENDING, RUNNING, COMPLETE, FAILED, REUSED and INVALID.

Missing-value semantics: NA means genuinely unavailable historical diagnostics or a not-yet-completed cell, distinguished by `artifact_status`. Missing endpoint values are never fabricated. The dataset is not complete or frozen until every canonical condition and integrity check passes.

Reproducibility instructions (from project root): run `.venv-highres/bin/python scripts/fixed_budget_dataset/audit.py` once to freeze the pre-training audit. Then `OMP_NUM_THREADS=4 PYTHONPATH=src .venv-highres/bin/python -u scripts/fixed_budget_dataset/run.py` resumes only missing jobs. Do not rerun the audit over a populated dataset. Interrupted incomplete jobs get a new attempt directory; fully completed jobs are validated and reused. A source hash mismatch stops reuse and requires investigation. Finalization writes a version and SHA256 and refuses to overwrite a frozen dataset.

No exposure-matched training or mechanism experiments are authorized by this build.

Continuous execution: `supervise.py --runner-pid PID` attaches to the existing runner and resumes ordinary process interruptions from `run_manifest.csv`; it never invokes the audit. Scientific assertion failures require diagnosis. `progress.py --watch` validates completed artifacts and maintains the source, checkpoint, mask, dense, and sparse manifests during execution. Its cache avoids reprocessing unchanged artifacts. `supervisor_status.json` and `incremental_manifest_status.json` distinguish execution state from dataset completion.

Winner reporting: numerical ties at tolerance 1e-12 retain every tied age. Winner matrices display every tied age. Unique-winner fields are NA when multiple minima occur, while a separately labeled representative age supports scalar summaries. Every tied mean winner receives paired boundary contrasts and dense/sparse decompositions. The full observed distance from the minimum and runner-up gap remain available without a post-hoc scientific near-tie threshold. Dense/sparse boundary decomposition keeps both direct endpoint changes so the source of a ticket-gap contrast can be inspected descriptively. Cross-architecture surface figures display measured grid points only.
