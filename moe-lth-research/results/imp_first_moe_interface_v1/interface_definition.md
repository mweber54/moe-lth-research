# First-MoE interface

The model is pre-normalized. Block 0 computes a = attention(attention_norm(input)); u = input + a; z = moe_norm(u); c = MoE(z); h = u + c. c includes fc1/fc2 biases, GELU, selected full-softmax confidence, top-1 assignment and whole-batch capacity acceptance. A forward hook replaces only the first MoE module's returned contribution tensor with alpha*c_d. The block's native residual addition remains active. Donor c_d is captured from its own unmodified forward on identical token/target positions and the complete original batch. F_r includes blocks 1–3, final_norm and the tied embedding/output head. No projection, alignment, gating again or rescaling is applied.

NATIVE_RESPONSE lets downstream routes respond. RECIPIENT_BASELINE_REPLAY fixes only layers 1–3 to the exact recipient's own baseline IDs, selected coefficients and acceptance/order, while experts consume current inputs. Layer 0 is never overwritten by recipient replay. Internal native router probabilities used by replay are not labeled imposed selections. Routing is not held identical across the two recipients.

Native interface statistics compare u, z, raw pre-temperature projection scores, selected confidence, ungated selected expert output including dropped positions, and complete c. Ungated differences are split by unchanged versus changed selected expert. Diagnostic selected-expert computation can be chunked after complete-batch routing has been captured; actual model dispatch is unchunked. Relative L2 uses the start tensor as denominator; global cosine and mean per-position cosine exclude zero denominators and record exclusions. Pair sufficient statistics support pooled validation metrics, rather than averages of batch RMS/relative changes. Substitution statistics retain sums of squares and elements, actual inserted/native/attenuation displacements, and post-addition residuals. Norm ratios use L2 norms on identical positions. Alpha-zero donor aliases have explicit logical rows but no independent status.

Task CE = sum actual token NLL / sum actual target counts (492416 over the original 31 batches including partial final batch); auxiliary loss is excluded. FP32, TF32 off, eval/inference.

V(r)=L(r,start,1)-L(r,end,1). Q=V(end)-V(start). S_start=L(start,end,1)-L(start,start,1); S_end=L(end,start,1)-L(end,end,1). A(r,d,a)=L(r,d,a)-L(r,d,1). T(d,a)=A(end,d,a)-A(start,d,a). Positive V means recovered donor helps; positive S means reciprocal substitution hurts; positive A means attenuation hurts; positive T means fixed-donor attenuation hurts more in the recovered recipient. Alpha .9 is the modest-attenuation primary contrast; .75,.5,0 are the fixed response curve. Sparse contrasts are same-seed sparse minus unpruned; routing contrasts are native minus replay. Diagonal A(end,end,0)-A(start,start,0) must equal prior ZERO_L0 damage change and is distinct from fixed-donor T. All identities are independently rechecked from exported absolute CE.

Layer 0 was chosen post hoc after examining the prior contribution-ablation study. This new design and implementation were sealed before new outcomes; this is not project-level preregistration. Validation was repeatedly examined and is not an independent test. Source seeds (n=5) are replication units; batches, tokens, alphas, layers and cells are nested measurements. The recipient context includes its own pre-addition residual representation and subsequent computation, not downstream weights alone. Donor and recipient share seed/model type; no alignment, norm matching, weight transplantation or training is performed. Usefulness is confined to tested recipient contexts, not universally better semantic information. Q is an evaluation compatibility interaction that can reflect coordinate mismatch, scaling, routing and subsequent use. Reciprocal harm does not prove semantic co-specialization. Frozen expert/router weights and biases do not learn. Fractional attenuation has different absolute sizes across donors, but fixed donor/alpha perturbations are identical across recipients. Norms and cosines do not establish usefulness or explain CE causally. Sparse-versus-unpruned donor perturbations can also differ in absolute magnitude. No percentage of recovery, training counterfactual, ticket mechanism, safe pruning rule or generalization beyond this architecture/mask family/window is identified. Nonmonotone curves and negative effects are retained.
