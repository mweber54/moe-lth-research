# Step-zero sign versus magnitude analysis

Inputs resolved from the completed surviving-value placement experiment whose logged initial IMP shuffle penalty is 4.84591133 nats. Authoritative manifest: results/imp_initial_value_placement_v1/variant_manifest.csv. Reference table: trajectory_losses.csv in that directory. All five source seeds and both original matched random-mask realizations are retained separately. No training, backward passes, optimizers, or checkpoint changes are authorized or used.

Step zero is the complete original random initialization, not a rewind to a later training step. IMP experts rewind to that original initialization. The full source checkpoint supplies routers, attention, embeddings/tied output head, normalization, expert biases and every other shared tensor. Sources/configurations and SHA256 identities are recorded in the authoritative variant manifest, and the reconstruction helper checks checkpoint and complete starting-state hashes. Saved checkpoint configs are copied here. Audit source: results/imp_initial_value_placement_v1/audit.md and scripts/imp_initial_value_placement_v1/run.py:variant_state.

Baseline gate: run the original _eval_one_snapshot function on each reconstructed original IMP and random mask. Fixed validation stream SHA256 09a073e9f03bbb854d3903081440b9e0869feb8e04b50b3b1be76a1d42658b22; 31 native batches and 492416 target tokens. FP32, TF32 off, complete native batches and capacity; float32 batch loss sums accumulated as Python float64, weighted by actual target counts. All 15 baselines reproduce exactly. baseline_reproduction.csv records each result. Any mismatch above 0.001 blocks perturbations.

A samples round(p*n) entries independently in each positive/negative survivor group and uniformly permutes their values. B samples round(p*n) survivors, then uniformly permutes their signs. C uses the survivor mean absolute value. D uniformly permutes all survivor values. F is identity. Five independently seeded draws for each condition; deterministic conditions C/F are repeated as pipeline checks. An isolated CUDA Generator seed is derived from the first eight SHA256 bytes (little endian, modulo 2^63) of sign-magnitude-step0-v1|seed|mask_arm|condition|dose|draw|tensor_name. Actual per-tensor RNG seeds are saved in rng_seeds.jsonl. No global RNG is consumed by transformations. Dose and draw transformations are independent; dose subsets are not nested.

E_A/E_B use independent Gaussian directions on all survivors of each matrix, normalized to exactly the corresponding A/B matrix displacement (relative tolerance 1e-6 in FP32). These are distance-conditioned Gaussian directions, not independent unscaled Gaussian amplitudes. Zero-distance matrices receive zero noise. Noise is not constrained to preserve signs or energy.

All treatments start independently from the original checkpoint. Only expert fc1/fc2 matrix survivors change. Masked entries stay zero; biases and router/shared state are reloaded unchanged for each treatment. Invariants are asserted for every transformed matrix and logged in each successful CSV row. A/B/D preserve FP64 matrix energy to rtol=atol=1e-12. F must reproduce CE exactly and routing change zero. No inference is drawn from incomplete output.

realized_distance is the Frobenius distance over all expert fc1/fc2 weights divided by the original norm over all those weights. For layer/projection ablations the unchanged matrices remain in the denominator. frac_sign_flipped likewise uses all expert survivors. Routing change is the fraction of evaluation tokens whose pre-capacity top-k expert set differs in at least one layer; set ordering is ignored. Layer names are zero-based native transformer block indices. Layer and projection ablations use the same tensor-specific RNG as the corresponding all-layer treatment, so unchanged tensor scopes are paired exactly.

Compare seeds separately; random realizations and draws are nested replications. No conclusions about any training step, including steps 1500–2500, are supported. Baseline CE is far above uniform chance ln(256)=5.545; a near-chance floor flag is not applicable. This unusual scale is preserved exactly, not corrected or retuned.

Engineering correction: the first attempt stopped when checking numerical nonzero counts against binary mask counts on the first random-mask treatment. Exact-zero original survivor values exist. The corrected invariant compares the unchanged binary mask and its row/column counts; numerical nonzero counts are not structural survivor counts. Failed-attempt logs are retained. A and B leave exact-zero-valued survivors fixed because they have no positive/negative sign; B samples only nonzero survivors. C uses sign(w)*mean(abs(w)), so exact zeros remain zero (an explicit exception to replacing every magnitude, required to preserve zero signs). D can move original zeros within survivors. zero_survivors_seed*_*.json reports each matrix's exact-zero count. The initial IMP rows passed the stronger nonzero-count assertion and therefore contained no zero survivors in transformed matrices; their B transformations are unchanged by this correction.

Distance-matched B is supplemental: independently permute positive and negative survivor index lists, pair them, and flip the closest prefix of opposite-sign pairs to A's squared matrix displacement. This is a sign permutation (disjoint transpositions), preserves position magnitudes and exact sign counts, and is selected solely from original weights and A displacement before evaluating CE. Its actual selected fraction and residual distance mismatch are reported. It is a different conditional permutation distribution from the prescribed uniform-subset B, so conclusions are conditional on both tested distributions.
