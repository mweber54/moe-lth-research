# Layer Mechanism Ranking

No layer can be ranked as causally responsible. The aggregate 500-1000 top-1 distribution TV means are: layer 0 R0/R20/R100 = 0.07377/0.04657/0.04448; layer 1 = 0.10753/0.06662/0.07900; layer 2 = 0.13583/0.09551/0.12682; layer 3 = 0.19011/0.20985/0.19674. Only layer 3 is larger for R20 than both alternatives on average, but that joint condition holds in only one of three seeds. Thus it is not a seed-consistent R20-specific layer candidate.

`layer_routing_contrasts.csv` contains the seed-level values. These are distribution shifts, not assignment churn because token identities were not stored. Persistent switches, token targeting, and expert-specific recoverability cannot be inferred.
