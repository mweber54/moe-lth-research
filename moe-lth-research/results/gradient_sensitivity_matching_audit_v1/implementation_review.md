# Implementation review

No intervention, gradient recomputation or model operation was performed. The original stopped study remains unchanged.

The original implementation follows its registered greedy algorithm: coordinate-disjoint row/sign/magnitude-stratum pair choices occur before column-cycle extraction. Coordinate availability is consumed exactly as specified. This can discard alternative admissible partners; it is an algorithm limitation, not a divergence from the registration. A synthetic case has zero pairs on the greedy-restricted graph and a two-pair cycle on the alternative graph.

The DFS reconstructs valid cycles; H-column to L-column edges correspond to the correct signed degree equation. Reversing every edge negates that equation and does not change feasible circulations. Exhausted black vertices cannot gain cycles when edges are deleted. Tests show that greedy cycle deletion can nevertheless return two edges when a different decomposition returns three; it is not maximum-cardinality circulation. Whole-cycle target packing is also heuristic. In the original data all yields were below656, the target was2621, and a simple cycle is at most1024 columns long: target remainder/rounding could not explain the stop.

Each pair removes one coordinate in each of two different branches. Dose per branch is k/262144, not2k/262144. Whole-expert dose sums retained pairs over67108864 expert-weight coordinates; shared weights and biases are outside this denominator. The bottom half has131072 coordinates;50 strata contain22 bins of2622 and28 of2621. Current signs are signed; magnitude, OLS growth and variation use absolute weights. OLS growth is multiplied by750 and normalized by full current tensor RMS; variation is normalized total absolute-magnitude variation, not net movement. Calipers .005,.1,.1 apply to these normalized features. Rows and columns use the original tensor width, not a transposed projection.

H/L roles are pair-relative. A coordinate can have admissible edges in both roles, so separate bipartite copies without a shared capacity constraint would double-use coordinates. The independent binary formulation enforces a single capacity across both roles. Row equality follows from same-row pairs; exact columns or TV<=.05 are imposed separately. Removed-energy balance is encoded as .995*E_H<=E_L and .995*E_L<=E_H, equivalent to the original symmetric relative bound. SMD and KS remain postchecks: optimality for encoded constraints is not optimality for all scientific gates.

A/C all-tensor candidates use the same original greedy edge choices, with C generated by an LP relaxation and integer flooring, not a certified binary maximum. B/C binary tests permit different pair choices on the fixed random subset. Any restricted graph, timeout, missing incumbent or absent bound is labeled explicitly. The zero assignment is feasible, so a solver infeasible status is an engineering/numerical issue rather than evidence of no scientific matching. Solver bounds are numerical optimization reports, not formal rational certificates.

The original roundoff-assertion and tensor-transport engineering corrections are preserved. Neither establishes that small yield was a bug. No concrete implementation defect has been inferred merely from low yield. Synthetic counterexamples identify expected greedy limitations; actual cohort implications are quantified in solver_results.csv.
