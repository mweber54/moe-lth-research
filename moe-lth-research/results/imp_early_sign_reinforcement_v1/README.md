# Early sign reinforcement in E32 IMP recovery

The run manifest is in `inputs.json`. It specifies the 162 perturbation jobs, 18 untouched baselines, exact step-0 checkpoint and mask identities, archived training and validation streams, and matched study dose targets. The archived random1 and random2 masks match IMP’s survivor count within each matrix. The archived generator samples surviving coordinates uniformly, and the measured row and column degrees differ from IMP. The recovery uses 2,500 update attempts, as in the original study. Applied and AMP-skipped steps are accounted for separately.

The dense probe runs until 100 AdamW steps apply and accumulates the signed and absolute gradient-driven displacement online in FP64. The post-step AdamW state reconstructs the displacement using bias-corrected moments. Decay is computed separately with the optimizer's FP32 parameter multiplication. Every active parameter is checked against its observed post-step value. `probe_audit.csv` gives routed exposure, eligibility, and numerical audit counts. Routed exposure includes the skipped AMP attempt and all 100 applied attempts.

Matching ranks the full eligible matrix before intersecting with each mask. Stratification uses starting sign and joint within-matrix magnitude and activity quantile bins. Within a common-support stratum each arm has the same count and uses its own deterministic random stream. The random arm samples uniformly without reinforcement ranks from the full surviving stratum. The final dry run uses the smallest archived global achieved distance as one target for all masks and scales each mask’s archived per-matrix dose profile to that target. The matching seal records the chosen dose and hashes the selections. The matrix audit reports starting sign, activity, magnitude, distance, reinforcement quantiles and the concentration of flips across rows and columns.

`per_run.csv` and `paired_results.csv` are published from verified job results. `seed_endpoints.csv` keeps A, B and their combined mean for each seed. `matched_retention.csv` compares retained high-reinforcement fractions using common-support matrix and covariate strata weighted by the smallest survivor count across masks. The endpoint plot and recovery curves are generated after all 54 triplets are available.

The dispatch keeps all three arms of a comparison on the same GPU. Each recovery stores a single atomic endpoint record after checking that the planned validation sequence and the 2,500 ordered update attempts are complete. Interrupted jobs retain the native optimizer, scaler and RNG interruption checkpoint. Restart the same worker shard from the repository directory to resume its checkpointed work. The numbered progress files and worker logs identify the active jobs.
