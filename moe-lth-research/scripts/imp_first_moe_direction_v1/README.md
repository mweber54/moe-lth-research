The specification is sealed before any new loss. FP64 norm/direction construction is first checked on the same four-complete-batch training-only probes used previously. Those probes were used in historical training and diagnostics, not held-out generalization data. `direction_eligibility.json` freezes the evidence, source hash and exact rule before validation interventions. Exact nonzero is preferred; there is no epsilon or floor. An unrepresentable FP32 hybrid fails before CE rather than generating a direction, silently dropping a position or adjusting a threshold.
